What's new in Prism

Version 0.9.31

Video picture, take two

Video frames were drawn, but never reached the screen: pages are drawn by Prism's GPU process, and the instruction for drawing a video frame there only existed on macOS, so it did nothing. Frames are now sent as images, once per frame.

Needs a new Prism WebKit build. Full screen video still isn't supported.

Video picture

The video player no longer skips drawing frames while it believes the page is hidden.

Crash recovery

  • Your tabs come back: if Prism crashes, is force-closed or the PC shuts down with it open, the next start offers to reopen the tabs you had, groups included. (With "Continue where you left off" on, they simply reopen.)
  • Crashed background tabs reload when you switch to them, instead of showing the crash page.
  • Crash reports: when Prism itself crashes, it saves a small report (where it crashed, no page contents) in %LOCALAPPDATA%\Prism\crashes. The newest five are kept; send one along if Prism keeps crashing.

Prism's own WebKit: the picture

  • The first Prism WebKit build streams YouTube in every quality, but only showed a dark frame. Video frames are now drawn into the page directly, the way WebKit on Windows can show them.
  • Full screen video isn't there yet: WebKit's Windows version has never had it. It's on the list for a later WebKit build.

Prism's own WebKit: WebCore compiles

  • All of WebCore, WebKit's biggest part, now compiles with streaming video on Windows. WebKit's processes on top of it now find GStreamer too.

Prism's own WebKit: last compile error

  • Restoring saved build progress no longer stops on files that are hard links (they were listed with the shortcuts by mistake). Progress saved while that bug was there is missing those files, so it's ignored and the next build starts fresh.
  • Fixes the only compile error left in WebKit's video player on Windows: a setting it uses was only declared for Linux's way of drawing video.

Prism's own WebKit: saving progress properly

  • The build now saves WebKit's header links in a list and makes them again exactly as they were, instead of relying on the archiver, which broke them ("file not found"). Older saved progress is ignored, so the next build starts fresh.

Prism's own WebKit: compile fixes

  • Fixes the first real compile errors in WebKit's streaming-video code on Windows: places where Windows' compiler is stricter than Linux's, and Linux-only parts that Windows doesn't have.

Prism's own WebKit: resuming builds

  • Saved progress now keeps WebKit's header links as links. Progress saved before this had copies instead, which made every header appear twice ("redefinition" errors); the build ignores that older progress and starts fresh by itself.
  • A WebKit build that carries on from saved progress no longer stops while setting up (Skia's header folders came back as copies instead of links).
  • WebKit's libraries are kept between runs even after GitHub updates its compilers, so they aren't all rebuilt each time.

Prism's own WebKit: first fixes

  • Fixes the compile errors from the first build of Prism's own WebKit: GStreamer now replaces Windows' old video player instead of sitting next to it, and WebKit reads GLib's Windows headers properly.
  • When the WebKit build fails, its summary now starts with a short list of the distinct errors and leaves out the thousands of warnings.

Streaming video: Prism's own WebKit

  • Why YouTube said "Your browser can't play this video": WebKit's Windows builds can't stream video (they have no Media Source Extensions), so YouTube and most video sites refuse to play.
  • The fix: Prism now builds its own WebKit on GitHub Actions, with the media player WebKit uses on Linux and smart TVs (GStreamer). It plays streaming video, with hardware decoding where your graphics card supports it.
  • Once that build is out, fetch-webkit.ps1 -Prism switches Prism to it. Prism sets up its video playback by itself; nothing needs installing.

Reading views (ACI)

  • Read any article your way: press Aa in the address bar (or F9) and Prism shows the article in a view made for how you read. The original page stays untouched underneath; "Original page" or Esc takes you back.
  • Focus: one calm column without ads, sidebars, pop-ups or moving things, a reading progress bar, and an option to bold the start of each word.
  • Dyslexia-friendly: Comic Sans by default (or OpenDyslexic, Lexend, Verdana, Arial, Century Gothic, Trebuchet, any font on your PC, or your own font file), wider letter and word spacing, a soft cream background, no italics.
  • Dense: smaller text and tighter spacing for more on screen.
  • Adjust text size, spacing, line length and background with Aa inside the view, and have a site always open in its view. On pages that aren't articles (like YouTube), Focus stops motion and pauses videos, and Dyslexia-friendly changes the page's font and spacing.
  • Settings › Reading views: open every page in a view, the font, and the sites with their own view.

Extensions in their own space

  • Isolated content scripts: the scripts extensions add to websites (Bitwarden's autofill, uBlock's page cleanup and so on) now run in a JavaScript space of their own, like in Chrome. They still see and change the page, but the website can't see, hook into or tamper with them. Scripts that extensions run on demand (executeScript) use the same space.
  • Passwords button: a lock button next to the Extensions button opens your saved passwords.

A new Extensions panel

  • Extensions panel: the puzzle button opens a panel listing your extensions, grouped by whether they can see and change the site you're on. Click one to open it, pin it to the toolbar, or use ≡ for its options, inspecting and managing. "Manage extensions" is at the bottom.
  • Icons from protected sites: when a site turns away Prism's own icon request (common behind bot checks), the page you have open now fetches its icon instead. Bookmarks for such sites get their icon the next time you visit them.
  • Performance log: Settings › About › Performance shows when Prism was too busy to answer pages and what it was doing, and which extensions made pages wait. If YouTube or another site freezes, copy it from there so the cause can be found.

More site icons

  • Site icons now load for more websites, on tabs and bookmarks, for example shops and documentation sites. Some sites sent icons in a format Prism didn't accept, or turned Prism away because its icon requests didn't look like they came from a browser.

Bookmark icons, and starting maximized

  • Bookmark icons: bookmarks show their site's icon on the bookmarks bar, in bookmark folder menus and on prism://bookmarks. For sites you haven't visited yet, Prism looks up the icon itself, one site at a time and without cookies.
  • Starts maximized: Prism opens maximized. If you close it while it's not maximized, it opens at that size and place next time.

Extensions see the browser they were made for

  • Inside their own pages, extensions from the Chrome Web Store (and unpacked ones) now see Prism as Chrome, and those from Firefox Add-ons see it as Firefox. Before, they saw Prism's Safari identity, and extensions like Bitwarden switched to their Safari version, which needs Apple's Safari app to work. Websites still see Prism as before.
  • The extension log also shows what an extension's pages receive: connections, messages and port messages, with the sender and how many listeners were waiting for them.

A more detailed extension log

  • An extension's log (Extensions › Details › Background page › Show log) now also shows which browser features it uses: the first use of each, any calls that fail (with the message they were sending), and anything still waiting for an answer after 5 seconds. This helps find where an extension like Bitwarden gets stuck while starting.

Seeing what extensions are doing

  • Background page status: an extension's Details on the Extensions page now show whether its background page is starting, running, stuck or stopped, and how often it crashed or reloaded itself.
  • Show log: shows the extension's console messages (background, popup and offscreen pages), plus Prism's own notes on starting, connecting and reloading. You can copy or clear the log. It works even when the developer tools won't open.
  • Prism warns on the Extensions page when an extension reloads itself over and over, which usually means it's failing to start.
  • Fixed: turning an extension off and on no longer leaves black areas on the Extensions page until you scroll.

Prism Passwords

  • A built-in password manager. After you log in to a site, Prism offers to save the password. Click a login field later to pick the account to fill in. On sign-up forms, Prism can suggest a strong password.
  • Encrypted on this computer only. Your logins are locked with a master password (AES-256, using Windows' own encryption) and never leave your PC. By default the vault opens by itself while you're signed in to Windows, but seeing, copying or exporting a password always needs the master password.
  • prism://passwords (also in the menu): search, view, edit and delete logins, a password generator, and import from Chrome, Edge, Brave, Firefox, Bitwarden or 1Password exports. Copied passwords are cleared from the clipboard after 45 seconds and kept out of Windows' clipboard history.
  • Ocean icon: Prism's icon is now the Ocean logo everywhere: on the taskbar, the window and the Prism.exe file.

An accent that follows the theme

  • The accent colour now follows the theme: Ocean blue with the dark theme and Amber with the light theme, like the logo. With "System", it changes when Windows switches between light and dark.
  • To use a different colour, pick your own in Settings › Appearance with the colour picker. Choose the split Ocean/Amber swatch to go back to the theme's colour.

Pick your own accent colour

  • Accent colours: Settings › Appearance now offers Ocean and Amber, matching the logo, plus a colour picker for any colour you like (drag in the square, slide the hue, or type a hex code). Ocean is the new default. If you picked another colour before, Prism keeps it as your custom colour.
  • Inspect extensions: an Inspect button on the Extensions page opens the developer tools for an extension's background page. Right-click an extension's button to inspect its popup, which then stays open until you click the button again.

Bitwarden works, and a new logo

  • Bitwarden's popup loads. Prism now supports offscreen documents, the hidden pages some Manifest V3 extensions keep part of their data in. Bitwarden couldn't read its storage without them, so its background kept restarting.
  • Extensions can see which of their pages are open (runtime.getContexts). Reloading an extension closes its popup, like in Chrome.
  • When an extension's background page crashes, fails to load or doesn't start properly, the Extensions page now says so, and also says when Prism stops restarting it.
  • New logo: the Facet logo in Amber on a light taskbar and Ocean on a dark one. It switches when you change Windows' theme. Prism's pages use it too.

Every request filtered

Prism Shields and blocking extensions now see the full address of every picture, script, frame and request a page makes, not just which site it goes to. Ads and trackers hosted on ordinary sites get blocked too, and the shield shows how many were blocked on the page you're on.

Fixed in 0.9.5

  • Extensions that stopped answering: when an extension's background was busy for a while (uBlock Origin and AdNauseam checking every request on YouTube, or compiling their filter lists), Prism took it for gone and never let it back in. Its popup then said "Could not establish connection. Receiving end does not exist." Backgrounds now stay connected however busy they get, and an extension page that does lose its connection reconnects by itself.

Fixed in 0.9.4

  • Errors from closed popups: closing an extension's popup (for example by right-clicking its button while it was open) could list an error like "Attempting to use a disconnected port object" on the Extensions page. Prism now stops the popup before disconnecting it.

New in 0.9.3

  • Stand-ins for blocked trackers: some sites break when a tracker script is missing. Prism Shields now loads a harmless stand-in instead (like a do-nothing Google Analytics), the way uBlock Origin does.
  • Tracking parameters are also removed from requests pages make, wherever filter lists say so.
  • Extensions' right-click menu items appear in the page's menu (for the page, links, pictures, videos, selected text and text fields) and on their toolbar button's menu.
  • Extensions' keyboard shortcuts work, and the Extensions page lists them. Prism's own shortcuts always come first.

New in 0.9.2

  • Extensions that block with webRequest, like AdNauseam and other uBlock-based extensions, now really block: they see every request a page makes and can cancel it or swap in a harmless stand-in. What they block counts toward the number on the shield.
  • If an extension takes longer than a second to answer, the page carries on without waiting.

Fixed in 0.9.1

  • Hidden ads that kept playing: Prism Shields hid YouTube's home page ad tile, but the video in it could still play out of sight. Videos that start inside a hidden ad, or in a player with no visible size, are now paused and muted. Videos you start yourself are never touched.

New in 0.9

  • Full network filtering: Prism Shields' filter lists now apply to complete addresses and file types (like example.com/ads/*.js), as in uBlock Origin and Brave.
  • Blocked on this page: a number on the shield in the address bar, and the list in the Shields panel (click the shield). You can still allow a domain from there if something breaks.
  • Blocking extensions like uBlock Origin Lite now apply their rules to full addresses too. The Extensions page shows how many rules are in use.
  • Alt+F4 closes the window, even while you're on a web page. Ctrl+Shift+W closes the whole window (Ctrl+W still closes the tab).

Still to come in 0.9: extension scripts kept apart from pages, and Prism's own WebKit build for printing, camera and microphone.

Fixed in 0.8.2

  • Extensions that save a lot of data (like AdNauseam, once its list of collected ads grows past 16 MB) lost their settings at every start, so AdNauseam showed its welcome page again. Prism now reads saved extension data of any allowed size, and saves it in the background so big extensions don't slow down browsing.
  • If an extension's saved data ever can't be read, Prism keeps the file aside instead of replacing it.

Fixed in 0.8.1

  • Sites whose certificate Windows didn't have yet (like example.com and example.org) couldn't be opened securely, so HTTPS first fell back to http. Prism now checks such a site once with Windows' own networking, which fetches the missing certificate authority from Windows Update if Microsoft trusts it, and then opens the page. Pages loading in other tabs at that moment may need a reload.
  • A site with a certificate that really isn't trusted now says so, with tips, instead of "Can't reach".

New in 0.8

  • HTTPS first: http:// addresses open with the secure https:// version. Sites without one open unsecured with a message, and an address-bar label says Not secure. Prefer to be asked first? Choose HTTPS only in Settings › Privacy. Your PC, local network devices and IP addresses are left as they are.
  • Tracking removed from links: click trackers like utm_source, fbclid, gclid and msclkid are taken out of addresses before pages open.
  • Fingerprinting protection: sites can try to recognize your PC from how it draws pictures and sound, its graphics card and its processor. Prism makes those details slightly different for every site and every time you start it, so they can't be used to follow you around.
  • Per-site switches in the Shields panel (the shield in the address bar): HTTPS, tracking removal and fingerprinting protection, for when a site needs an exception. Settings › Privacy lists them.

Fixed in 0.7.3

  • After an update, this page no longer opens in another new tab when it's already open from last time: Prism switches to that tab instead.

Fixed in 0.7.2

  • Extensions can find and close their own tabs again: AdNauseam's "Let's go!" button on its welcome page did nothing.
  • Extension pages show as chrome-extension://… in the address bar again, instead of their http://….localhost address.

Fixed in 0.7.1

  • Background tabs no longer start playing videos (like YouTube opened in the background, or tabs from last time). They start when you switch to them, like in Safari. Something already playing keeps playing when you switch away.
  • Pages no longer think the mouse is still over them after you switch tabs, so YouTube's hover previews don't start by themselves.
  • Ads right after starting Prism: pages opened while Prism Shields was still loading (such as tabs from last time) didn't get Shields' site fixes, so YouTube could show an ad. Those pages now wait for Shields (5 seconds at most), and Shields starts with the filter lists it already has, updating them afterwards.

New in 0.7

  • Tab groups. Right-click a tab › Add tab to new group. Right-click a group to name it, change its color, collapse it, add a tab or close it. Links you open from a grouped tab join its group, and groups come back with your tabs. Choose how they look in Settings › Tabs:
    • One row: each group is a colored label followed by its tabs; click the label to collapse it.
    • Two rows: your groups on top, the selected group's tabs below. The selected group always comes first, so Ctrl 1 goes through its tabs; Ctrl 2–9 pick the others as shown. Drag a group to give it a new place.
  • Drag tabs to reorder them, or next to a grouped tab to add them to that group.
  • Vertical tabs: put your tabs in a list on the left (Settings › Tabs), with groups as folders. The button at the top narrows it to icons.
  • Site icons in tabs, the bookmarks bar, History, Bookmarks and on the new tab page. Prism downloads them itself, without cookies, and keeps them on your PC.
  • Right-click a tab for New tab to the right, Reload, Duplicate, Close other tabs and Close tabs to the right.
  • Colors: six palettes for Prism's toolbar and pages, Prism, Midnight, Nord, Forest, Rosé and Sepia, each in dark and light (Settings › Appearance).
  • Your own CSS (Settings › Custom CSS): restyle Prism's interface, or any website, site by site.
  • New tab page: shortcuts to your most visited sites (or your bookmarks bar) and your own background picture. A Home button is available too.
  • Extensions menu: the puzzle button now lists your extensions. Choose which ones get a button in the toolbar, or right-click a button › Hide from toolbar.
  • Fixed: with many tabs open, the + button was cut off.

New in 0.6

  • Bookmarks. Click the star in the address bar (or press Ctrl D) to bookmark a page. Your bookmarks bar sits under the address bar (Ctrl Shift B shows or hides it); folders open as menus, and bookmarks that don't fit are under ». Right-click one to rename or delete it.
  • Bookmarks page (Ctrl Shift O): folders, search, drag to reorder or move, and editing. Import from Chrome, Edge, Brave, Vivaldi or Opera in one click, or from an HTML file (Firefox and most browsers can export one). Export to HTML too.
  • History (Ctrl H): every page you visited in the last 90 days, by day, with search. Remove single pages, or clear the last hour, day, week, four weeks or everything. It stays on your PC, and you can turn it off in Settings › Privacy.
  • Address-bar suggestions from your history and bookmarks. Use ↑ ↓ to pick one. What you type isn't sent anywhere until you press Enter.
  • Find in page (Ctrl F), with a match count. Enter or F3 goes to the next match, Shift for the previous one.
  • Permission prompts. When a site wants your location or to show notifications, a bar under the address bar asks. Allow or Block is remembered for that site; ✕ just says no this time. Notifications appear as Windows notifications; click one to go to its tab. Change your answers, or block all requests, in Settings › Site permissions.

Good to know

  • Printing isn't available yet: the Windows version of WebKit has no way to print pages. It comes with Prism's own WebKit build in 0.9. Until then, Ctrl P says so.
  • Camera and microphone aren't available yet either, for the same reason (also planned with Prism's own WebKit build).
  • Location comes from Windows. If a site can't find you, check that Location is on in Windows Settings › Privacy & security › Location, including "Let desktop apps access your location".
  • Content scripts still run in the page itself, and extension right-click menu items, keyboard shortcuts and webRequest blocking aren't supported yet (0.9).
